# LoRAForge v1.0 evidence release

This release preserves the selected epoch-2 QLoRA adapter from the completed
Tesla T4 experiment. It requires the pinned base model
`mistralai/Mistral-7B-Instruct-v0.3` at revision
`c170c708c41dac9275d15a8fff4eca08d52bab71`; it is not a merged or standalone
model.

## Verified outcome

- Publisher-test rows: 7,600.
- Untuned base macro-F1: 0.7261902147623102.
- Selected QLoRA macro-F1: 0.9332520991438105.
- Macro-F1 delta: +0.2070618843815003.
- Final test evaluations recorded: 1.
- Selected epoch: 2.

## Verify the repository evidence

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
PYTHONPATH=src python -m loraforge.cli verify --root . --reports-only
```

This recomputes the stored validation and test metrics from raw logits without
requiring adapter files. Omit `--reports-only` for strict verification when
both epoch checkpoint directories and `adapters/selected/` are available.

## Limitations

The result is one seed and one T4 run on a constrained four-class benchmark.
It does not establish open-ended generation improvement, multi-seed variance,
medical performance, or production readiness. See `docs/results.md`.
